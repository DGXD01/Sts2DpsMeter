# 储君单人卡牌伤害覆盖

## 基线

- 游戏程序集：`E:\STEAM\steam\steamapps\common\Slay the Spire 2\data_sts2_windows_x86_64\sts2.dll`
- 游戏版本：`0.107.1`
- 卡池来源：`MegaCrit.Sts2.Core.Models.CardPools.RegentCardPool`
- 卡池数量：88 张
- 额外 Token/派生牌：`SovereignBlade`、`MinionStrike`、`MinionSacrifice`、`MinionDiveBomb`、`Debris`
- 当前范围：储君单人卡牌；多人归属和敌方能力来源另行验证
- 数据整理日期：2026-09-19

本文档记录从游戏程序集反编译得到的伤害指令，以及 Mod 当前采用的归因方式。卡名以游戏内部类名为准；统计显示名使用游戏运行时提供的本地化标题。

## 统计原则

1. 同一张卡牌的多次命中、多个目标和升级版本合并为一个统计类型，使用稳定卡牌 ID 聚合。
2. 直接伤害由 `DamageCmd` 或带 `CardModel` 的 `CreatureCmd.Damage` 产生，直接归因到实际造成伤害的卡牌。
3. `SovereignBlade` 和 `MinionStrike` 是独立 Token 卡牌，伤害始终归入 Token 自身，不回溯给锻造、转换或强化它的卡牌。
4. `BlackHolePower` 和 `ReflectPower` 静态映射到唯一来源卡牌 `BlackHole`、`Reflect`；来源列表显示能力名，卡牌明细使用映射后的卡牌 ID。
5. 锻造、重放、格挡和伤害倍率修正只改变 `SovereignBlade` 的数值或重复次数，不改变伤害来源。
6. 自动打出、生成、转换得到的卡牌，按实际被打出的卡牌稳定 ID 统计，例如 `Bombardment`、`MinionStrike`、`MinionDiveBomb`。
7. 当前没有按“同一回合内所有伤害”做隐藏合并；每张牌按稳定卡牌 ID 建立统计类型，`打击`、`痛击` 等不同卡牌保持分开。

## 代码覆盖结果

### 直接伤害

游戏程序集中共有 32 张储君卡牌包含直接伤害指令：

`AstralPulse`、`BeatIntoShape`、`Bombardment`、`CelestialMight`、`CollisionCourse`、`Comet`、`CrashLanding`、`CrescentSpear`、`CrushUnder`、`Devastate`、`DyingStar`、`FallingStar`、`GammaBlast`、`GuidingStar`、`HeavenlyDrill`、`Hegemony`、`HeirloomHammer`、`KinglyKick`、`KinglyPunch`、`KnockoutBlow`、`LunarBlast`、`MakeItSo`、`MeteorShower`、`PhotonCut`、`Radiate`、`SevenStars`、`ShiningStrike`、`SolarStrike`、`Stardust`、`StrikeRegent`、`Supermassive`、`WroughtInWar`。

这些卡牌依赖 `CardModel` 上下文和稳定 `Id`，不需要在 `DpsAttribution` 中逐张硬编码；卡牌名、升级版本和同名合并由统计层处理。

### 能力间接伤害

| 卡牌 | 能力 | 触发方式 | 当前归因 | 状态 |
| --- | --- | --- | --- | --- |
| `BlackHole` | `BlackHolePower` | 花费星能打出卡牌，或获得星能时 | 来源为 `BlackHolePower`；卡牌明细映射到 `BlackHole` | 已覆盖，待运行验证 |

除上述两项外，储君专属能力没有发现直接 `DamageCmd` 或 `CreatureCmd.Damage` 调用；其余能力主要提供星能、锻造、格挡、重放或伤害倍率修正。

| Token | 伤害路径 | 当前统计落点 |
| --- | --- | --- |
| `SovereignBlade` | 基础攻击伤害，可由锻造强化、重放或获得格挡 | `SovereignBlade` |

### 强化、生成与自动出牌

- `ConquerorPower`、`SwordSagePower`、`ParryPower`、`SeekingEdgePower` 只修改 `SovereignBlade` 的伤害倍率、重放次数、格挡或目标范围；伤害仍归入 `SovereignBlade`。
- `ForgeCmd` 创建或强化 `SovereignBlade`，代表卡牌包括 `BeatIntoShape`、`BigBang`、`Bulwark`、`Conqueror`、`RefineBlade`、`SeekingEdge`、`SpoilsOfBattle`、`SummonForth`、`TheSmith`、`WroughtInWar`。
- `Bombardment` 会重新自动打出自身，伤害仍归入 `Bombardment`。
- `DecisionsDecisions` 自动打出选择的技能牌，`IAmInvincible` 自动打出抽牌堆顶牌；伤害归实际自动打出的卡牌。
- `Begone` 转换为 `MinionStrike`，`Guards` 转换为 `MinionSacrifice`，`Charge` 转换为 `MinionDiveBomb`。
- `BundleOfJoy`、`Largesse`、`ManifestAuthority`、`Quasar` 生成无色牌；其后打出的伤害按实际生成卡牌统计。
- `CollisionCourse`、`CrashLanding` 生成 `Debris`；`Debris` 当前不产生伤害。

## 待游戏内验证

- `BlackHolePower` 在“花费星能”和“获得星能”两种触发路径下是否只记录一次，并确认卡牌明细归入 `BlackHole`。
- `ReflectPower` 只在有来源的受击并产生格挡时反弹，确认反弹伤害归入输出而不是承伤。
- `SovereignBlade` 的锻造、`ConquerorPower` 倍率、`SwordSagePower` 重放、`ParryPower` 格挡是否只改变数值和命中次数，不改变来源 ID。
- `Begone` 转换出的 `MinionStrike`、`Guards` 转换出的 `MinionSacrifice`、`Charge` 转换出的 `MinionDiveBomb` 是否保持稳定卡牌 ID。
- `Bombardment` 自动重打自身时是否合并到 `Bombardment`；`DecisionsDecisions` 和 `IAmInvincible` 自动打出的牌是否归入实际卡牌。
- `BundleOfJoy`、`Largesse`、`ManifestAuthority`、`Quasar` 生成的无色牌是否在打出后按实际卡牌统计。
- `CollisionCourse`、`CrashLanding` 生成的 `Debris` 是否保持无伤害，不会影响原卡牌统计。
- 储君卡牌生成的临时卡、复制卡、升级版本和跨战斗卡牌是否保持稳定卡牌 ID 分组。

## 当前限制

- `BlackHolePower` 和 `ReflectPower` 的当前来源列表仍保留能力名，卡牌明细通过 `TriggerCardId` 归到对应卡牌。
- 储君能力可能被其他未来卡牌、遗物或药水施加；静态映射只在当前 `0.107.1` 版本中成立，新增来源后必须重新审计。
- 本文档依据程序集静态分析整理，编译通过不代表游戏内事件顺序、目标选择和控制权归属已经完全验证。
