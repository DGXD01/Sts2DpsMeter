# 铁甲战士单人卡牌伤害覆盖

## 基线

- 游戏版本：`0.107.1`
- 卡池来源：`MegaCrit.Sts2.Core.Models.CardPools.IroncladCardPool`
- 卡池数量：87 张（源码声明为 `new CardModel[87]`）
- 反编译源码：`E:\Slay the Spire 2\辅助生成文件\DPS检测Mod\反编译\sts2-0.107.1`
- 额外 Token：`GiantRock`
- 当前范围：铁甲战士单人卡牌的本体伤害、自损、能力间接伤害和生成/触发边界
- 暂不纳入本文档：多人归属、遗物效果、药水效果、敌方能力来源
- 数据整理日期：2026-09-20

本文档记录从游戏程序集反编译得到的伤害指令，以及 Mod 当前采用的静态归因方式。卡名以游戏内部类名为准；统计显示名由游戏运行时本地化标题提供。本文档只证明代码路径已梳理，不代表游戏内事件顺序和归属已经实机验证。

## 统计原则

1. 同一张卡牌的多次命中、多个目标、升级版本按稳定卡牌 ID 合并为一个统计来源。
2. 卡牌本体直接伤害由 `DamageCmd.Attack(...).FromCard(this)` 产生，归因到实际造成伤害的卡牌。
3. 卡牌本体自损由 `CreatureCmd.Damage(... base.Owner ...)` 产生，归入自损统计，不计入对敌输出。
4. 能力造成的间接伤害只在能够稳定确定唯一卡牌来源时静态映射；无法静态确定时保留为能力来源。
5. 生成牌、复制牌和自动打出的牌以实际造成伤害的稳定卡牌 ID 为准，不把伤害回溯给生成者或触发器。
6. 玩家受到的敌方攻击属于承伤，不属于自损；由自身卡牌或自身能力造成的玩家受伤才归入自损。
7. 力量、虚弱等增伤或减伤只改变最终伤害，不拆分来源。例如 2 点力量下“打击”造成 8 点，只记录“打击 8 点”，不额外记录“力量 2 点”。

## 代码覆盖结果

### 直接伤害

共 37 张卡牌包含卡牌本体直接伤害指令：

`Anger`、`AshenStrike`、`Bash`、`Bludgeon`、`BodySlam`、`Break`、`Breakthrough`、`Bully`、`Cinder`、`Conflagration`、`Dismantle`、`Feed`、`FiendFire`、`FightMe`、`Headbutt`、`Hemokinesis`、`HowlFromBeyond`、`IronWave`、`Mangle`、`MoltenFist`、`PactsEnd`、`PerfectedStrike`、`Pillage`、`PommelStrike`、`Rampage`、`SetupStrike`、`Spite`、`Stomp`、`StrikeIronclad`、`SwordBoomerang`、`TearAsunder`、`Thrash`、`Thunderclap`、`TwinStrike`、`Unrelenting`、`Uppercut`、`Whirlwind`。

这些卡牌依赖 `CardModel` 上下文和稳定 `Id`，不需要在 `DpsAttribution` 中逐张硬编码。多段伤害、全体伤害、升级版本和同名聚合由统计层处理。

### 自损

共 7 张卡牌包含卡牌本体自损指令：

`BloodWall`、`Bloodletting`、`Brand`、`Breakthrough`、`DemonicShield`、`Hemokinesis`、`Offering`。

这些调用均使用 `ValueProp.Unblockable | ValueProp.Unpowered | ValueProp.Move`。自损单独计入自损统计，不计入对敌输出。`Breakthrough`、`Hemokinesis` 同时包含直接伤害和自损，两个方向必须分开记录。

### 自动出牌、生成与派生子牌

- `Anger` 攻击后生成自身副本；副本实际打出时仍归 `Anger`。
- `Cascade`、`Havoc` 自动打出抽牌堆顶牌；伤害归实际打出的卡牌。
- `HowlFromBeyond` 消耗后在自动出牌阶段重打自身；伤害仍归 `HowlFromBeyond`。
- `InfernalBlade` 生成随机攻击牌；后续按实际生成的卡牌统计。
- `PrimalForce` 将手牌中的可转化攻击牌转为 `GiantRock`；`GiantRock` 作为独立 Token 统计。
- `Stoke` 消耗整手牌并生成等量铁甲战士卡；后续按实际生成卡牌统计。
- `Juggling` 在每回合第 3 张攻击牌后生成其副本；副本的伤害按实际副本卡牌 ID 统计。
- `Hellraiser`、`OneTwoPunch`、`Stampede` 触发或增加攻击次数；伤害归实际攻击牌，不归触发能力牌本身。
- `Aggression`、`Rupture`、`Vicious` 等只提供抽牌、升级或力量修正，不产生直接伤害事件。
- 力量、虚弱、脆弱、`CrueltyPower`、`TankPower` 等只改变最终伤害、目标关系或承伤归属，不拆分为独立伤害来源。

## 分类校验

- 卡牌本体直接伤害：37 张。
- 卡牌本体自损：7 张。
- 同时具有直接伤害和自损：2 张，即 `Breakthrough`、`Hemokinesis`。
- 其余 45 张：不包含上述两类卡牌本体伤害指令，其中部分包含能力、生成或自动出牌路径。
- 总数校验：`37 + 7 - 2 + 45 = 87`。

## 待游戏内验证

- 37 张直接伤害卡是否全部落到稳定卡牌 ID，多段攻击、全体攻击和击杀是否只记录一次。
- 7 张自损卡是否全部进入 `SelfLoss`，且不会污染对敌输出、DPS 或最高单次伤害。
- `Breakthrough`、`Hemokinesis` 的直伤与自损是否在同一张牌下分栏显示且互不合并。
- `CrimsonMantlePower`、`InfernoPower` 的回合开始自损是否归到对应卡牌。
- `FlameBarrierPower` 反伤是否只在符合条件的有来源受击后产生，并归入输出而不是承伤。
- `InfernoPower` 未格挡受伤后的全体伤害是否只触发一次，并归入 `Inferno`。
- `JuggernautPower` 由卡牌、能力、遗物或药水提供时，是否能区分唯一来源；无法确定时必须回退到能力来源。
- `GiantRock`、`Anger` 副本、`HowlFromBeyond` 重打、`Juggling` 副本和 `Stoke`/`InfernalBlade` 生成的牌是否保持稳定卡牌 ID。
- `Hellraiser`、`OneTwoPunch`、`Stampede` 触发的攻击是否归实际攻击牌，而不是触发能力牌。
- 力量、虚弱、脆弱、`CrueltyPower` 等修正是否只改变最终伤害数值，不新增独立来源。
- `Tank` 在多人模式下的承伤转移、玩家归属和是否计入自损，留待多人专项验证。

## 当前限制

- 本文结论来自 `0.107.1` 程序集静态审计，尚未完成游戏内运行态验证。
- 能力可能被未来卡牌、遗物或药水施加；本文静态映射只在当前版本的现有来源范围内成立。
- 多人模式中的玩家归属、队友承伤转移、敌方能力和团队统计不在本次单人卡牌覆盖范围内。
- 遗物效果和药水效果不纳入本文档，后续按独立清单审计。
- 编译通过或静态分类完整，不代表事件顺序、目标选择、控制权、死亡截断和随机多目标已经完全验证。
