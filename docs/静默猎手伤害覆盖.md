# 静默猎手单人卡牌伤害覆盖

## 基线

- 游戏程序集：`E:\STEAM\steam\steamapps\common\Slay the Spire 2\data_sts2_windows_x86_64\sts2.dll`
- 游戏版本：`0.107.1`
- 卡池来源：`MegaCrit.Sts2.Core.Models.CardPools.SilentCardPool`
- 卡池数量：88 张
- 额外 Token：`MegaCrit.Sts2.Core.Models.Cards.Shiv`
- 当前范围：静默猎手单人卡牌；多人归属和敌方能力来源另行验证
- 数据整理日期：2026-09-19

本文档记录从游戏程序集反编译得到的伤害指令，以及 Mod 当前采用的归因方式。卡名以游戏内部类名为准；统计显示名使用游戏运行时提供的本地化标题。

## 统计原则

1. 同一张卡牌的多次命中、多个目标和升级版本合并为一个统计类型，使用稳定卡牌 ID 聚合。
2. 直接伤害由 `DamageCmd` 或带 `CardModel` 的 `CreatureCmd.Damage` 产生，直接归因到实际造成伤害的卡牌。
3. 生成并打出的 `Shiv` 单独按 `Shiv` 统计，不把伤害回溯给生成它的卡牌。
4. 中毒伤害统一归入 `PoisonPower` 的“中毒/持续伤害”统计；`AfterPowerAmountChanged` 会记录施加层数和来源模型，唯一来源时标记 `Tracked`，混合或未知来源回退为 `Deferred`。
5. 只对能够稳定确定唯一来源的能力做静态映射；共享能力 `ThornsPower` 使用运行时卡牌来源记录，无法确定唯一来源时保留为能力来源。
6. 当前没有按“同一回合内所有伤害”做隐藏合并；每张牌按稳定卡牌 ID 建立统计类型，`打击`、`痛击` 等不同卡牌保持分开。

## 代码覆盖结果

### 直接伤害

游戏程序集中共有 27 张静默猎手卡牌包含直接伤害指令：

`Assassinate`、`Backstab`、`DaggerSpray`、`DaggerThrow`、`Dash`、`EchoingSlash`、`Finisher`、`Flechettes`、`FlickFlack`、`GrandFinale`、`LeadingStrike`、`MementoMori`、`Murder`、`Neutralize`、`Pinpoint`、`PoisonedStab`、`Pounce`、`PreciseCut`、`Predator`、`Ricochet`、`Skewer`、`Slice`、`Strangle`、`StrikeSilent`、`SuckerPunch`、`Suppress`、`TheHunt`。

这些卡牌依赖 `CardModel` 上下文和稳定 `Id`，不需要在 `DpsAttribution` 中逐张硬编码；卡牌名、升级版本和同名合并由统计层处理。

### 中毒路径

`PoisonPower` 由 `AfterSideTurnStart` 触发伤害。静默猎手可以通过以下 9 张卡牌直接或间接施加中毒：

- 直接施加：`BouncingFlask`、`BubbleBubble`、`DeadlyPoison`、`Haze`、`PoisonedStab`、`Snakebite`
- 通过能力持续施加：`CorrosiveWave`、`Envenom`、`NoxiousFumes`

`Accelerant` 增加中毒触发次数，不创建新的伤害来源；`Mirage` 根据敌方中毒层数计算格挡；`Outbreak` 在敌方被施毒达到阈值后造成能力伤害。上述卡牌都不会让中毒伤害改归其自身：

- 中毒伤害：稳定归入 `PoisonPower`
- 唯一来源：`PoisonSourceInfo` 保留施毒卡牌、施加层数和 `Tracked` 状态
- 混合或未知来源：保留 `PoisonSourceInfo.Deferred`，不强制归给某一张牌

### 能力间接伤害

| 卡牌 | 能力 | 当前归因 |
| --- | --- | --- |
| `Abrasive` | `ThornsPower` | 运行时记录唯一卡牌来源；多个来源时保留为 `ThornsPower` |
| `Outbreak` | `OutbreakPower` | 静态映射并在有运行时记录时使用实际来源 |
| `SerpentForm` | `SerpentFormPower` | 静态映射并在有运行时记录时使用实际来源 |
| `Speedster` | `SpeedsterPower` | 静态映射并在有运行时记录时使用实际来源 |
| `Strangle` | `StranglePower` | 卡牌直伤和持续能力伤害均归入 `Strangle` |

`ThornsPower` 不能静态映射为 `Abrasive`，因为它还可能来自其他卡牌、遗物、药水或敌方效果。运行时记录只有在来源唯一时才会把它归到对应卡牌；检测到混合来源后，统计会回退到 `ThornsPower`，避免错误归因。

### Shiv 派生伤害

`Shiv` 是 Token 卡，基础伤害为 4、升级后提升，并带有 `Shiv` 标签。当前统计把它作为独立卡牌类型处理。以下卡牌会生成、触发或修改 Shiv：

- 生成：`BladeOfInk`、`BladeDance`、`CloakAndDagger`、`FanOfKnives`、`HiddenDaggers`、`InfiniteBlades`、`LeadingStrike`、`StormOfSteel`、`UpMySleeve`
- 触发已有 Shiv：`KnifeTrap`
- 修改 Shiv：`Accuracy`、`FanOfKnives`、`PhantomBlades`

这些卡牌自身的伤害统计不会吞并 Shiv 伤害；Shiv 打出时产生的伤害继续归入 `Shiv`。

## 待游戏内验证

- `Abrasive` 单独和与其他反伤来源叠加时，`ThornsPower` 是否正确归为 `Abrasive` 或保留能力名。
- `OutbreakPower` 的伤害是否能在事件链中稳定解析为 `Outbreak`。
- `SerpentFormPower`、`SpeedsterPower` 的随机/连锁伤害是否只归因一次，且不会把伤害错误归给触发它的卡牌。
- `StranglePower` 在目标出牌后的伤害是否与 `Strangle` 直伤合并显示。
- `Shiv` 的 `FanOfKnives`、`Accuracy`、`PhantomBlades` 修正是否只影响伤害数值，不改变来源 ID。
- 中毒使用唯一来源、多个来源和未知来源时，分别确认 `Tracked` 能保留施加层数、`Deferred` 不误归，并验证中毒伤害仍归入中毒机制统计。
- 静默猎手卡牌生成的临时卡、复制的卡牌和跨战斗卡牌是否保持稳定卡牌 ID 分组。
