## 1. 基线、范围与结果

- 分支：`refactor/HUD布局与刷新基础`，工作类型为重构。
- 起点：文档分支提交 `292912b`；代码基线为远程 `main` 的 `9e702c0`，Mod 版本 `0.2.1`，游戏程序集版本 `v0.107.1`。
- `feature/DebuffDamageAttribution` 的独立开发内容尚未进入此基线，本次没有合并该功能分支，也没有替换当前游戏安装的 Mod。
- 原始 Markdown 与 Word 开发说明保持原文。实现范围为实施计划第 1 步的布局、齿轮入口和刷新基础。
- 新增来源图标、Tooltip、自定义字段、详情展开、Scope 语义调整等仍按后续阶段实施。
- 不新增持久化字段，设置 Schema 保持 `4`；伤害归因、统计快照和战斗计时逻辑没有改动。

本步实现：

1. 统计行使用容器排列固定 16 px 图标预留位、可伸缩名称列、右对齐伤害列和百分比列。所有可见行统一测量数字列宽，长名称裁切，避免数字长度影响各行对齐。
2. 普通来源名及多人职业色富文本均放入受限名称列；保留玩家颜色、BBCode 转义及本地玩家标记。
3. 设置按钮改为齿轮（⚙），保留原设置面板及鼠标交互；没有新增暂停菜单入口。
4. 标题字体由 19 调整为 14，面板圆角、边距和间隔缩小；长标题裁切，可悬停查看完整标题。
5. 统计分组和数据行仅在池容量不足时创建，多余分组/行隐藏，切换后重新绑定；内容不变的行跳过文字/数值更新。
6. 任意线程的刷新入口只标记请求，由 `DpsMeterHost._Process` 每帧最多消费一次；保留 0.25 秒轮询作为计时展示兜底。
7. 仅在内容、布局或视口改变时重算面板尺寸；尺寸上限计入 UiScale，已裁入屏幕的位置不会在无变化轮询时被旧保存坐标覆盖。
