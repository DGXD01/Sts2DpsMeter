## 定位与本地修复

原绘制路径把“⚔”等特殊字符写入启用裁切、省略的固定 16px Label；开关及来源类型已到达 UI（截图显示卡牌详情和已勾选项）。字体字形或窄列裁切是可疑点，但没有运行原生场景，未断言二者中哪一项是实际原因。此前“字符串非空”的离线检查无法证明图标可见。

本轮替换这条脆弱绘制路径：

- 用 TextureRect 显示内置的十种 SVG 基础图元：卡牌、闪电、宝石、药瓶、球体、爪印、敌人、星形事件、回转箭头及未知问号；不是游戏卡牌缩略图。
- 32px SVG 以 2 倍采样生成 64px 透明纹理，在固定 16 逻辑像素列内居中、等比、线性过滤；保持现有蓝色，紧凑模式同样占 16px 列。
- 按类型缓存纹理，主线程首次遇到时生成，后续复用；非法类型归一化为 Unknown，不按内部 ID 或任意枚举值无限增建。
- 关闭图标时清空纹理而不隐藏列；非来源指标/空行没有类型时保留空列。TextureRect 忽略鼠标，不拦截已验收的悬停、点击和滚动。
- SVG 解码失败时记录警告并缓存透明问号位图回退，同样不依赖字体。
- 移除旧符号映射；设置 Schema、选项默认值、伤害统计及归因没有更改。
