## 1. 判断与修改

代码可确认：旧 HUD 正文为 12/13 号字，叠加 2 像素黑描边；标题为 14 号、3 像素描边，HUD 没有自己的明确字体主题。小字配较粗描边可能影响字形与边缘观感，截图差异与此相符。截图经过聊天缩放，且未检查实际渲染字体，因此不能把某一种字体或采样方式认定为唯一根因。

本地参考 Mod 的字体初始化也采用系统字体、2 倍采样与 Normal hinting；本轮自行实现独立 HUD 字体主题，不复制参考 Mod 的界面系统或资源。Godot 的字体回退与采样语义参照 [SystemFont 官方说明](https://docs.godotengine.org/en/stable/classes/class_systemfont.html)，缩放影响参照 [Using Fonts](https://docs.godotengine.org/en/stable/tutorials/ui/gui_using_fonts.html)。

| 项目 | 修改 |
| --- | --- |
| 字体 | HUD 使用独立 SystemFont，优先 Microsoft YaHei UI / Microsoft YaHei，回退 PingFang SC、Noto Sans CJK SC、Segoe UI、Arial，并允许系统补齐字形 |
| 渲染 | 2 倍采样、Normal hinting、自动子像素定位；只缓存两套正常/粗体实例，供普通文本与多人富文本使用，不改游戏共享字体或全局项目设置 |
| 字号 | 正常正文/数字 13→16，紧凑 12→14，标题 14→16，范围 12→14，详情 11→13；图标仍用较小字号适配固定列 |
| 描边与对比 | 来源行和标题改为 1 像素描边；白色正文，提亮标题蓝色、箭头及次要文字 |
| 行高 | 正常 28→30，紧凑 24→26，给新字体留空间，避免只放大文字造成裁切 |
| 标题空间 | 单人/无玩家时隐藏两枚无效的玩家箭头；多人仍保留原有切换与禁用逻辑，标题释放空间时触发重新布局 |
| 位置 | 布局后的面板原点落在整数坐标，右/下边界向下取整，保持缩放后的面板在屏内；未改写永久位置设置 |

伤害数据、Scope 语义、第二步图标/提示/详情/字段、设置 Schema、程序版本和已发布更新包均未在本轮改动。不提前加入第 9 步 FontScale 设置或主题切换功能。
