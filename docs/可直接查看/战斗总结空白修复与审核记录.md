## 根因与修改

Godot 4.5.1 [Label::get_minimum_size 官方源码](https://github.com/godotengine/godot/blob/4.5.1-stable/scene/gui/label.cpp#L900)表明：开启自动换行时，若同时启用裁切或省略，最小文字高度返回 1。总结使用 WordSmart + TrimEllipsis，VBox 按最小值给五个标签各 1px；五行加间距/边距仅 45px，所以文本虽然已生成但没有可见行。每帧设置面板高度 0 会让面板持续收缩到这一错误最小值；关键修复是恢复标签自然最小高度。

仅将本总结标签的 TextOverrunBehavior 改为 NoTrimming，并添加原因注释。保留 WordSmart 自动换行、MaxLinesVisible=2、长来源长度限制、字体、清晰度、鼠标穿透、计时、设置和统计逻辑。没有扩大到其他 HUD 控件的省略行为，没有改数字或归因。
