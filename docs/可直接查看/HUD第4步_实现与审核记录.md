## 功能与设置

| 项目 | 实现 |
| --- | --- |
| 四边/四角吸附 | 默认开启，候选位置用蓝色框预览；拖动过程中面板跟随鼠标，松开后才应用并保存 |
| 吸附距离/留白 | 默认 24/12 视口像素，可分别在 4–80 / 0–64 范围调整；不随 UiScale 倍增；关闭磁吸时不应用留白 |
| 边缘方向恢复 | 保存水平/垂直吸附方向；缩放、分辨率或明细高度变化后重新定位；无吸附方向的旧配置仅限制可见位置 |
| 拖动边界 | 仅从标题栏开始，以同 CanvasLayer 全局鼠标差计算；至少移动约 3 像素才保存，避免普通点击触发；锁定/失焦/隐藏取消拖动；释放事件遗漏由帧检查兜底 |
| 低干扰 | 关闭/淡化/自动折叠，默认关闭；战斗中离开 HUD 约一秒后触发，快速划过不立即触发 |
| 临时淡化 | 整个 HUD 的 alpha 默认 0.30，可调 0.25–0.40；与用户原背景 PanelOpacity 相乘，恢复后 alpha 为 1，原配置不改写 |
| 临时折叠 | 保留标题、范围、齿轮和展开按钮，不改原手动折叠变量；移回恢复原手动状态，手动本来收起的仍收起；点击展开可解除临时折叠 |
| 恢复条件 | 移回 HUD、打开设置、拖动、范围菜单打开、战斗结束、隐藏或失焦均解除临时状态；不注册热键 |
| 设置兼容 | Schema 6；新增开关、距离、留白、方向、模式和临时 alpha 的默认/范围/非法值/Clone/JSON 支持，旧 Schema 4/5 保留已有值 |

吸附方向以边缘为准，不假设固定屏幕分辨率。若视口太小，留白减小至可容纳范围；原生最小尺寸大于视口时安全定位至原点，不能保证内容完全容纳，仍须实机小窗口验证。手动折叠在本次运行内保留原行为，没有新增跨重启持久化承诺。

## 发布新包后的测试步骤

1. **磁吸和候选框**：齿轮 → 位置，确认磁吸开启、距离 24、留白 12，取消位置锁定。拖标题到右上角附近，按住时只看蓝框，松开后位置才对齐并保存。依次验证四角及四边中间，自由区域不吸附，快速点击标题不移动。
2. **开关和参数**：关闭磁吸，自由拖到边缘，应没有蓝框或自动留白；再开启并改变距离/留白，预览和松开应一致。重置位置回到左上，原吸附方向不应把 HUD 拉回旧边缘。锁定后拖动无效，拖到窗口外释放或切换窗口不应留下拖动状态/蓝框。
3. **缩放与位置恢复**：吸附右下角，分别试 75%、100%、150% 缩放；边缘留白保持合理。更改游戏分辨率及重启后检查位置仍可见；明细行数或折叠高度变化后底边对齐。不要用外部脚本修改真实配置。
4. **关闭模式**：保持原面板透明度和手动展开，低干扰设关闭。战斗中移开鼠标超过一秒，HUD 不应变化；快速划过不应误触。
5. **淡化模式**：设置原面板透明度例如 0.82，低干扰选淡化、临时 alpha 0.30。关闭设置，战斗中移开约一秒应淡化；移回、打开设置、拖动或战斗结束应恢复。再次打开设置确认原 0.82 未改变，范围、标题全文及来源行提示仍可用。
6. **自动折叠**：先手动展开，自动折叠模式下移开一秒只保留标题和按钮；移回恢复明细。再手动收起后重复，恢复后仍手动收起；点击“+”能展开，不会永久卡在临时折叠。范围菜单/设置打开时不应自动收起。
7. **保存和边界**：重启后磁吸开关/距离/留白/方向和低干扰模式/alpha 保留，永久透明度未变。非战斗不进入临时模式；连续多场、新战斗、中文/英文、小窗口、其他 Mod、多人/全队列为后续矩阵，不把尚未测试项目标记通过。
