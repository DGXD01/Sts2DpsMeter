## 用户可见改动

齿轮顶部“HUD 布局预设”之后新增“HUD 主题”，三项选择：

| 主题 | 主视觉 |
| --- | --- |
| 默认深色 / Default Dark | 黑色背景、蓝色强调、红色进度条，沿用既有风格 |
| 游戏融合 / Game Blend | 深棕背景、暖金标题/边框、暖白文字及棕红进度条 |
| 高对比 / High Contrast | 黑底白字/边框、黄色标题、青色交互和深青进度条 |

HUD、设置、下拉菜单/弹出项、按钮状态、复选框、滑块/滚动条、来源图标/进度条、模块标题、行详情、原生提示、独立标题浮层、战斗总结及磁吸候选框统一取主题值。玩家职业色保留，仅中性/次要字和你标记跟随主题。游戏融合为轻量颜色风格，不增加游戏纹理依赖。

选择后一次 Save、请求 HUD 下一帧刷新，并延迟重建设置；不需要新伤害或重开面板。主题改变只重设现有节点样式，数据行以独立主题条件失效，数值不变时仍可更新颜色，隐藏行再次使用时也会更新。原生主题最多缓存三套，字体使用 Mod 独享基主题的复制，不改游戏共享资源；基本尺寸/边距跨主题一致，不改变字段/模块/统计/布局语义。

四预设新增一次复制主题：极简/默认→默认深色，详细→高对比，多人→游戏融合。显示白名单扩为29字段，其他保护不变；之后可手动换主题，刷新、保存或载入不重新套预设。位置/锁定、磁吸、UiScale（单独切主题时）、行数、面板透明度、低干扰和总结参数保持。仅点击预设仍按原约定一起调整其展示参数。

## 发布后用户验收步骤

先确认Steam已完成0.2.17更新并由用户正常重启游戏，加载0.2.17后再检验；旧0.2.16不含主题，不能用来验收本轮功能。

1. **三主题即时切换**：齿轮→HUD主题→依次选默认深色/游戏融合/高对比。没有继续出牌时已有静态行也应立即换色；设置页无需关闭重开就同步。比较主背景、边框、标题、图标、进度条与次要字，不能只有标题换色。
2. **设置与菜单**：各主题下打开范围、主题、提示详细度等下拉框；检查弹出菜单文字/选中项，按钮普通/悬停/按下态、复选框已选/未选、滑块及滚动条均可辨认。
3. **详情/提示/总结**：关闭设置，在来源行悬停、展开行详情，再悬停标题全文；不同主题都应清晰。下一次战斗结束总结沿用当前主题，仍显示五行并自动关闭，奖励点击穿透不变。
4. **只改视觉**：切换前后核对总伤害、命中、行数、模块开关、字段、排序、范围、玩家选择、位置和缩放均不被切主题改掉。战斗中DPS可能随时间正常变化，不据此判为伤害被重算。
5. **四预设联动**：极简/默认应转默认深色、详细转高对比、多人转游戏融合；之后单独换主题并改一项字段/行数，关闭设置、等待刷新，配置不得被持续套回。单人应用多人预设仍为单人界面。
6. **兼容行为**：各主题尝试折叠/展开、拖动/磁吸、低干扰淡化与恢复。位置/锁定/吸附方向、面板透明度、总结开关/时长和已配置渐变保持。候选框强调色跟随主题，布局不异常跳动。
7. **保存/可读性**：选游戏融合或高对比后由用户正常退出重启，确认主题及手改参数仍在；旧配置首次更新为默认深色且原参数保留。用现有UiScale（0.5–2.0）及紧凑模式观察长名称、中英文和数字，不应模糊、重叠或裁掉关键操作。高对比可在正常透明度先对照观察。
8. **多人延后**：职业色/你标记、玩家/自己/全队、当前手选和新战斗默认在真实联机时统一测试，本轮不登记通过。
