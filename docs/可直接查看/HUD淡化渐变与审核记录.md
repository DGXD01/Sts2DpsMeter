## 最终行为与实现

- 保留战斗中鼠标离开 HUD 约一秒后触发。进入淡化后约 0.18 秒平滑降低至用户选择的临时 alpha，默认 0.30。
- 鼠标移回或其他恢复条件成立后，约 0.18 秒恢复为正常调制 alpha 1；原背景 PanelOpacity 不变，也不写真实设置文件。
- 过渡采用两端平缓的插值，快速反复移入/移出或更改目标时，从当前显示值开始，保持数值连续，不跳回起点。
- 复用已有 Host 的每帧信号，在统计刷新之后单独推进透明度；统计面板的 0.25 秒轮询只沿用当前动画值，不把目标值直接写到画面，不为动画每帧重建统计或布局。
- 隐藏、重建及 Host 退出时重置动画。自动折叠时机、手动折叠、磁吸、统计口径、Schema 6 和当前版本元数据 0.2.11 均保留。

## 新包复验

1. 战斗中选择低干扰“降低透明度”，关闭设置。鼠标移开超过约一秒，预期出现短暂、清楚可见的逐渐变淡过程。
2. 鼠标移回 HUD，预期约 0.18 秒逐渐恢复，整个过程中齿轮、来源行、标题提示仍可交互。
3. 在变淡途中迅速移回，再移开；预期从当前透明度反向，既不闪白也不突然跳到最淡。
4. 保持悬停/离开并让伤害数据刷新，预期动画不会被统计刷新打断；打开设置、拖动、战斗结束后仍平滑恢复，原面板透明度不变。
5. 磁吸、关闭低干扰及自动折叠快速复查；本轮不增加折叠尺寸动画。
