## 实现与口径

### UI-04 标题摘要

设置入口：HUD 齿轮 → 标题摘要。总伤害、DPS、DPT、承伤、回合数、命中次数六项复选，默认只显示伤害。最多同时三项；已满时需要先取消一项，再选择另一项，不能通过第四项点击静默挤掉已有选择。手工配置超过三项时按上述字段顺序归一化保留前三项。

摘要独立于统计模块开关，全部关闭只显示范围；多人选中玩家时保留其名称。长标题沿用现有固定最小宽度、裁切和悬停全文，不用完整标题文本撑大面板。所有设置与说明提供中英文。

| 范围 | 伤害/命中/承伤 | DPS | DPT |
| --- | --- | --- | --- |
| 本场战斗 | 当前玩家当前战斗总量；承伤包含敌方伤害和自损 | 该玩家伤害 / 本场耗时 | 该玩家伤害 / 当前战斗回合号 |
| 本回合 | 当前玩家当前回合快照；命中汇总该回合卡牌/来源记录 | 本回合伤害 / 本回合耗时 | 本回合伤害，即除以一个回合 |
| 全队 | 当前战斗所有玩家总量；不混入队友能量等辅助指标 | 全队伤害 / 同一场战斗耗时，不平均玩家比率 | 全队伤害 / 当前战斗回合号 |

回合数摘要在各范围显示当前战斗回合号；零或非法耗时的 DPS 为 0，空回合的伤害/承伤/命中为 0，不借用全场数据。回合计时沿用既有活跃战斗 Tick 入口，新回合只清空回合耗时，重复通知同一回合不清空；战斗结束停止累计、新战斗/重置清空。没有改变原全场耗时或暂停口径，TD-017 的暂停等实机边界继续保留。

### UI-05 范围语义

单人菜单只有本场战斗、本回合；多人增加全队/Team，不再称为总计/Total。范围使用稳定 ID，玩家数量从多人退回单人、旧内部第三档或非法值会回退本场，并清理详情/滚动状态。

全队仍显示当前战斗的玩家排行，左右箭头在全队禁用；本场/本回合仍可切换玩家。没有新增 Run Total、跨战斗累计或第五步的自己/当前玩家快捷模式。范围未新增持久化设置，不捏造旧配置中的范围字段。

### UI-06 排序

入口：HUD 齿轮 → 数据行 → 排序方式。默认总伤害/数值降序；另有百分比降序、命中降序、最大伤害降序、名称按字符顺序升序、最近触发优先。

先过滤原有不显示的零伤害行，再对完整模块排序，最后取 MaxRows；辅助零值行继续按原规则保留。百分比的分母仍是整个模块总量，因此同模块中百分比排序通常与伤害排序一致，截断显示不将剩余行重新归一化为 100%。

同值先按显示名称，再按稳定来源/玩家键排序；输入顺序改变不会让同值同名行抖动。缺失命中、最大或触发信息的行排在有该指标的行之后；辅助指标缺少相应记录时用稳定名称顺序，不伪造字段。

最近触发使用战斗内单调递增的伤害事件序号，不用刷新帧、累计伤害变化或字典枚举猜测时间。同一伤害事件的多人分配共享序号，顺序写入来源、回合卡牌及机制累加器；本回合承伤/自损分别保留该回合最后序号，合并来源取最大值。元数据经只读快照进入 UI，不改变伤害分配、累计总量、命中或最大值。

设置 Schema 保持 5，新增字段具备默认值/Clone/JSON 往返/Normalize。旧 4/5 配置保留原值并得到默认摘要和排序；非法排序回退总伤害。旧程序忽略新增字段，但不把旧程序当作已支持这些功能。
