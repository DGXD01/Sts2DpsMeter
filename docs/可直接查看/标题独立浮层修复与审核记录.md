## 本轮修改

- 通过已有原生 SceneTree.ProcessFrame 驱动标题区域检测；使用标题本地鼠标坐标适配 HUD 缩放，不依赖标题原生 TooltipText、进入信号或自定义 Node 的 _Process 绑定。
- 停留约 0.4 秒后显示同 CanvasLayer 的独立 PanelContainer。复用清晰字体和 UiScale，完整摘要一项一行，长名称自动换行；当前悬停期间固定数值，移开重入取得最新值。
- 浮层是复用节点，正文仅在快照变化时更新；浮层及子控件忽略鼠标，保留原标题拖动和来源行交互。
- 在可见范围内调整位置，底部不足时翻到标题上方。移出、任意鼠标按键、拖动、失焦、隐藏 HUD、Host 退出树时关闭并重置停留时间。
- 设置窗口盖住标题或范围菜单打开时不触发；设置窗口打开但没有覆盖标题时仍可查看。不将第三方窗口/游戏所有覆盖层都视作已验证。
- 保持三个摘要字段上限、统计公式、范围与排序、设置 Schema 和当前发布版本号不变。

## 新包加载后的复验

1. 选择伤害、DPS、DPT，把鼠标停在标题文字上约半秒；预期出现清晰的逐行完整摘要，来源行原有提示继续正常。
2. 保持悬停，预期内容稳定；移开消失，再悬停显示最新值。快速划过或按住鼠标时不出现浮层。
3. 未锁定时拖动标题、锁定后再尝试；确认无遗留浮层或拖动退化。折叠后仍可悬停标题。
4. 设置窗口没有覆盖标题时可以显示；覆盖标题或打开范围菜单时不触发。移出游戏窗口后关闭，返回需重新停留。
5. 在常用 UiScale、右边缘和底边测试，不应截断全文；中英文、长玩家名和多人/全队、其他 Mod 的覆盖层仍需后续验收。
