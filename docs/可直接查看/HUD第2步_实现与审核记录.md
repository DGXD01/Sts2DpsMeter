## 2. 新增行为

- 固定 16 逻辑像素的图标列，区分 Card、Power、Relic、Potion、Orb、Pet、Event、Unknown，兼容 Enemy 和 Self；未知新枚举回退问号。同类型使用统一小符号，非来源指标及空行不冒充来源类型。关闭图标后保留列宽，数值列不跳动。
- Tooltip 提供简洁、详细、开发者三级，默认详细。只显示该行 Snapshot 实际具备的指标。归因置信度、追溯状态和内部 ID 仅在开发者模式出现；混合来源不冒用第一条记录的类型、置信度或 ID。原生 Tooltip 负责悬停出现/移开关闭，长名称按文本元素换行，保留全文。
- 点击统计行展开/收起详细信息，全 HUD 同时最多一行展开；展开内容保持详细模式，不随开发者 Tooltip 泄露内部信息。切换范围、玩家及新战斗时清除；隐藏、排序或复用节点时按稳定来源键匹配，不按行位置绑定。同名玩家使用 NetId 区分。
- 来源行点击优先用于详情，拖动标题栏移动 HUD；滚轮交给外层明细滚动容器。不注册键盘焦点或热键，不依赖自定义 Godot 虚方法。
- 名称、数值、百分比、命中次数、最大伤害、平均伤害六个字段独立开关。默认保留名称+数值+百分比。隐藏名称时显示行号，悬停识别来源；字段全部关闭时保留名称。数值列在全部可见行之间统一测量、右对齐，并为滚动条预留宽度；超宽文本裁切，完整数据可从提示或展开详情查看。
- 设置 Schema 4 → 5。缺失新字段采用安全默认值，旧 MaxRows/缩放等保留；新开关、枚举和全部字段通过实际 Clone/JSON 序列化路径保存。非法 Tooltip 枚举回退详细模式。

## 3. 数据边界与口径

| 行类型 | 数据来源与限制 |
| --- | --- |
| 本场输出来源 | SourceStatsSnapshot，提供类型、命中、最大、格挡/生命/过量及已有归因元数据 |
| 本回合输出来源 | 当前 Turn 的 CardDamageSnapshot 按既有 CardId/GroupId 分组；总量/命中求和，最大值取最大，不借用全场指标；快照不具备的置信度/机制不补猜 |
| 本场承伤/自损 | 维持既有按名称合并，指标汇总，混合类型回退 Unknown；不改变现有合并语义 |
| 本回合承伤/自损 | 快照只有汇总量和类别，缺失命中、最大等字段不伪造 |
| 多人输出排行 | 使用各 PlayerStatsSnapshot 的实际总量、命中、最大和拆分；同名玩家键保持独立 |
| 格挡、能量、队友辅助 | 使用原有指标名和总量，不伪造伤害命中/最大/平均；缺失的可选数值列为空，Tooltip 不显示无意义占位 |

来源、回合卡牌和机制累加器仅增加 `MaxHit = Max(MaxHit, damage)`，并在只读 Snapshot 中暴露。伤害总量仍为现有口径（格挡+生命+过量），平均值为该总量/命中次数；多人份额分配、来源归因、回合计数和统计生命周期均未重写。此前用户截图中 56/55 的差异没有被本轮改动“修正”，仍待核对。

开发版程序元数据保持 0.2.4，工坊仍是此前发布包；本轮新增功能尚未发布，不得把本地 DLL 当作线上 0.2.4 的相同内容。新版本号与工坊日志在用户授权发布时再同步。
