## 行为与选择

| 项目 | 行为 |
| --- | --- |
| 快捷入口 | 多人且 HUD 展开时，在标题下增加快捷框和身份行；单人隐藏；折叠/自动折叠时隐藏，保留原来标题、范围和按钮 |
| 当前玩家 | 使用当前选中玩家的本场或本回合统计；按稳定 NetId 记住对象，不按伤害排名/名字定位 |
| 自己 | 使用 IsLocalPlayer 标记，保留职业色及“你”标签；未识别本地身份时显示等待，不把他人数据当自己 |
| 全队 | 复用原当前战斗汇总和玩家排行，与范围框“全队”同步，保留完整总量及原有份额口径 |
| 左右箭头 | 全队中禁用；自己中点击会进入当前玩家视图并选前/后玩家；当前玩家循环切换，不改变本场/本回合范围 |
| 时间范围 | 个人模式保留本场/本回合；去全队后再回个人恢复之前的个人范围。范围框主动选本场/回合时从全队回到之前的个人模式 |
| 默认视图 | 齿轮“多人视图”设置，默认当前玩家以保持旧行为；每场新战斗首次出现多人数据时应用一次，修改设置仅影响后续新战斗，当前手选不被轮询覆盖 |
| 战斗识别 | 只读快照新增可选 CombatId，真实 BeginCombat 在现有锁内递增，会话内不随 ResetRun 复用，避免漏过结束帧或计时较大时误判；不改变伤害生命周期 |
| 变化与回退 | 排名变化保持同一 ID；被选玩家不在时安全回退本地玩家/首位。空队伍和单人回退原个人视图；自己等待时本地身份补齐自动恢复 |
| 兼容 | Schema 7，旧 Schema 4/5/6 保留原字段；新增字段接入默认、非法值归一化、Clone/JSON。新菜单打开时不会触发低干扰或标题浮层遮挡菜单 |

快捷身份行复用既有职业色/本地标记富文本构建，玩家名转义；全队排行数据与统计核心保持原路径。没有新增多人伤害归因、Run 累计或战斗结束总结。

## 新包发布后的测试

1. **单人回归**：不显示多人快捷行，原范围、图标/详情、标题浮层、磁吸及淡化/恢复保持。
2. **多人当前玩家**：展开 HUD 查看新快捷框和玩家名，用左右箭头逐个切换。伤害数字增长或排名变化后仍是同一玩家；同名时也不应串数据。
3. **自己**：选择自己，核对本地名字、职业色、“你”及伤害；本场/本回合分别与该玩家数据一致。按箭头应进入当前玩家模式，不继续锁在自己。
4. **全队与范围**：快捷框选全队，范围框同步全队、箭头禁用，队伍总量和排行正确；选择自己或当前玩家回个人，恢复原时间范围。再通过范围框切全队/本场/本回合，两个入口应一致。
5. **三个默认与保存**：设置当前玩家、自己、全队各一次，在后续新多人战斗检查默认生效。当前战斗手动切换后等待刷新/出牌，不应跳回默认；重启后默认设置保留。
6. **身份与队伍变化**：数据登记较晚时自己显示等待，补齐后恢复。玩家/队伍变化时不崩溃或假冒自己；无多人条件时保留本项待验。
7. **布局/交互**：中英文、长名、常用缩放、折叠与自动折叠、低干扰淡化、磁吸边缘、新菜单打开/关闭、来源详情清理均复查。多人未具备时不能将本轮标记原生验收通过。
