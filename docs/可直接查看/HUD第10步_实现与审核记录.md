## 最终实现

设置顺序：HUD → 位置 → 统计内容 → 数据行 → 多人 → 战斗结束 → 预设。关闭按钮和配置路径置于末尾，所有选项仍从HUD齿轮进入。

- HUD：显示/紧凑、透明度、独立缩放与重置、主题、低干扰及标题摘要。
- 位置：锁定、磁吸、距离/留白、重置位置。
- 统计内容：伤害、承伤、格挡、能量和队友辅助模块。
- 数据行：排序/最大行数、图标、三级提示、详情与六字段。
- 多人：新战斗默认视图及玩家身份策略说明。
- 战斗结束：总结开关、时长及生命周期说明。
- 预设：四布局预设及恢复全部推荐值；重置提示说明其会影响位置、缩放、主题和总结。

重构将设置构建代码拆为partial文件，统一七组顺序及双语名称。主题、字号、字段等触发重建时按滚动比例恢复；以generation避免过期延迟任务写入新内容。面板按当前逻辑视口约束位置/大小，订阅尺寸变化并在节点退出时解除订阅，正文只纵向滚动。没有引入设置字段，因此Schema保持已发布的10，不降回原规划建议的5，也不为分组空升版本。程序和工坊版本仍为0.2.18，开发DLL不是已发布DLL。
