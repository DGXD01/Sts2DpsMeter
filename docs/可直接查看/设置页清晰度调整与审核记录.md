## 1. 设置页修改

原因已确认：0.2.6 字体主题仅应用到 HUD Panel，设置页为同 CanvasLayer 下的独立 Panel，没有继承这套主题；其说明、数值与字段标签仍有多处 11/12 号字号。

- 设置根面板接入同一套独立系统字体与 2 倍采样。复用已有主题缓存，不修改游戏共享资源或 HUD 已确认的字号与采样。
- 标题 18 号、分组/选项/下拉值/滑块数值与标签 16 号、说明与配置路径 14 号；提亮说明文字与正文，沿用细描边。
- 下拉弹出菜单是独立窗口，显式共享主题，使用局部字号覆盖 16 号，避免只清晰化选中值却遗漏菜单。未修改共享 Theme 的 PopupMenu 字号，因此 HUD 范围菜单保持原有样式。
- 滚动区取消固定 520px 高度下限，用面板剩余高度伸缩。面板原来的 485×650 尺寸和位置保持，放大说明文字后不再叠加该固定下限。
- 滑块/下拉行的标签最小宽度从 130 调整到 150，并允许自动换行，为新字号和英文标签留空间。
- 设置项顺序、默认值、Schema 5、保存逻辑、统计开关、数据范围和伤害计算没有在本轮修改；没有提前重做第 10 步的设置分组。

当前代码元数据仍为 0.2.6 的本地开发状态；已发布工坊包不包含本次设置页调整。上传工作区保持此前成功发布的 0.2.6，不能以版本号相同认定 DLL 内容相同。

## 2. 第二步骤到底增加了什么

入口：HUD 齿轮 → 在设置页向下滚动到“数据行”。

| 功能 | 玩家能看到/使用的变化 |
| --- | --- |
| UI-07 来源图标 | 用固定小图标区分卡牌、状态/能力、遗物、药水、充能球、宠物、事件等；可开关，关闭后仍保持列对齐，未知类型有回退 |
| UI-08 悬停 Tooltip | 鼠标停在来源行上查看信息；简洁/详细/开发者三级，按快照已有数据展示占比、命中、最大、平均及格挡/生命/过量伤害；归因置信度、追溯状态和内部 ID 仅在开发者模式出现 |
| UI-03 点击行详情 | 点击统计行展开，再点收起；同时最多展开一行，范围/玩家/新战斗切换后清除，不让详情串到其他来源 |
| UI-14 六字段配置 | 独立开关名称、数值、百分比、命中次数、最大伤害、平均伤害。默认名称+数值+百分比；隐藏名称时保留行号并可悬停识别，全部关闭时保留名称 |

配套增加：来源、回合卡牌和机制只读快照的最大单次记录；设置 Schema 4→5 的兼容与持久化；保留节点复用和列宽缓存。缺失的命中/最大等指标不伪造，能量/格挡/队友辅助不冒充伤害统计。原有伤害归因与总量口径保持不变。

第二步代码和离线检查已完成；图标字体、Tooltip、点击、组合布局和多人切换的完整实机验收仍待完成。用户本轮确认的是 HUD 的清晰度，不据此把全部第二步功能标记为验收通过。
