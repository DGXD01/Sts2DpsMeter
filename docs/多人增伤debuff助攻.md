# 多人增伤 debuff 助攻

## 目标与入口

多人战斗中，敌方单位身上的增伤 debuff 会让攻击者的实际伤害高于没有这些效果时的伤害。本功能允许玩家决定这部分“额外伤害”有多少计入 debuff 施加者。

设置入口：

```text
HUD -> 设 -> 多人伤害归属 -> 增伤 debuff 助攻权重
```

- 范围：`0` 至 `1`
- 步长：`0.05`
- 默认值：`0`
- `0`：保持旧行为，额外伤害全部留在实际攻击者。
- `0.5`：额外伤害由攻击者和 debuff 施加者各占一半。
- `1`：额外伤害全部转给 debuff 施加者。

本功能只改变 Mod 内部的伤害归属、来源明细和排行，不修改游戏实际伤害、卡牌、敌人、奖励或存档。

## 适用范围

当前参与助攻计算的增伤来源：

| 来源 | 显示名 | 计算基础 |
| --- | --- | --- |
| 易伤 | `助攻：易伤` | `VulnerablePower` 的伤害提升倍率 |
| 易伤强化 | `助攻：易伤强化` | `DebilitatePower` 对易伤倍率的强化部分 |
| 侧击 | `助攻：侧击` | `FlankingPower` 的增伤倍率 |
| 击倒 | `助攻：击倒` | `KnockdownPower` 的增伤倍率 |
| 减速 | `助攻：减速` | `SlowPower` 层数换算出的增伤倍率 |

助攻只在以下条件同时满足时计算：

1. 伤害属于玩家对敌输出；
2. 目标为敌方单位；
3. 攻击属于有效攻击伤害；
4. 能识别伤害来源和目标；
5. 存在由其他玩家施加的增伤 debuff 份额；
6. 权重大于 `0`。

攻击者自己施加的 debuff 份额不会转给自己，也不会凭空生成助攻。

## 计算公式

设：

```text
D = 本次攻击总伤害
P = 所有适用增伤倍率的乘积
k = 增伤 debuff 助攻权重
```

额外伤害：

```text
extra = D - D / P
```

多个 debuff 同时存在时，按各自对总倍率的对数贡献拆分：

```text
debuff_i 贡献 = extra * ln(multiplier_i) / ln(P)
```

某位非攻击者实际获得的助攻：

```text
助攻_i = debuff_i 贡献 * k * 非攻击者施加份额
```

例如，攻击总伤害为 `150`，易伤倍率为 `1.5`，只有一名队友施加易伤：

| 权重 | 额外伤害 | 攻击者 | 易伤施加者 |
| --- | ---: | ---: | ---: |
| `0` | `50` | `150` | `0` |
| `0.5` | `50` | `125` | `25` |
| `1` | `50` | `100` | `50` |

多个玩家分别施加 debuff 时，先按 debuff 贡献拆分，再按各玩家对应的施加份额拆分。攻击者本人持有的份额留在攻击者。

## 守恒与显示规则

- 攻击者从其 `blocked`、`unblocked`、`overkill` 和总伤害中扣除转移量。
- 助攻者把转移量加入对应的三类伤害和总伤害。
- 所有玩家的总伤害之和保持不变。
- 助攻不计入 `Hits`，不会增加玩家、卡牌、机制或来源的命中次数。
- 最高单击仍以助攻转移前的原始攻击伤害为准。
- 助攻计入伤害实际发生的当前回合，不计入 debuff 最初施加的回合。
- 转移总量不超过本次攻击总伤害；取整余数使用最大余数法分配，保证三类伤害分别守恒。
- 每个玩家的来源明细合计必须等于该玩家的总伤害。

## 明确排除

- 虚弱：虚弱降低攻击者输出，不属于目标受到的增伤，不产生助攻。
- 力量、活力等攻击者自身增伤：仍归实际攻击来源。
- 中毒、灾厄击杀、持续伤害、反伤、承伤和自损：不属于本功能的攻击增伤路径。
- 非敌方目标、非攻击伤害、未知施加者或无法确认施加份额的 debuff。
- 攻击者自己施加的 debuff；不会生成自我助攻。

## 自动验证

仓库内的 `scripts/test-debuff-invariants.ps1` 覆盖：

- 助攻资格和 `0..1` 权重边界；
- 额外伤害公式；
- 转移总量取整与封顶；
- 多来源按权重分配；
- `blocked`、`unblocked`、`overkill` 三类伤害守恒；
- 越界转移时整体回退；
- 基础攻击计命中、助攻不计命中；
- 灾厄击杀关闭助攻转移；
- 设置默认值、范围和步长。

运行命令：

```powershell
.\scripts\test-debuff-invariants.ps1
```

## 已知风险

- 当前自动测试覆盖纯计算和静态接入约束，尚未完成多人游戏内回归。
- 助攻来源依赖 `PowerModel` 的玩家份额；异步施加、混合来源或份额回退场景需要实机确认。
- 助攻来源的命中次数显示为 `0` 是既定口径，不表示伤害为 `0`。
- 设置面板新增内容后的低分辨率布局尚未在游戏内确认。
