# 亡魂契约师单人卡牌伤害覆盖

## 基线

- 游戏程序集：`E:\STEAM\steam\steamapps\common\Slay the Spire 2\data_sts2_windows_x86_64\sts2.dll`
- 游戏版本：`0.107.1`
- 卡池来源：`MegaCrit.Sts2.Core.Models.CardPools.NecrobinderCardPool`
- 卡池数量：88 张
- 额外 Token/派生牌：`Soul`、`SweepingGaze`
- 当前范围：亡魂契约师单人卡牌；多人归属和敌方能力来源另行验证
- 数据整理日期：2026-09-19

本文档记录从游戏程序集反编译得到的伤害指令，以及 Mod 当前采用的归因方式。卡名以游戏内部类名为准；统计显示名使用游戏运行时提供的本地化标题。

## 统计原则

1. 同一张卡牌的多次命中、多个目标和升级版本合并为一个统计类型，使用稳定卡牌 ID 聚合。
2. 直接伤害由 `DamageCmd` 或带 `CardModel` 的 `CreatureCmd.Damage` 产生，直接归因到实际造成伤害的卡牌。
3. Osty 攻击使用 `DamageCmd.Attack(...).FromOsty(base.Owner.Osty, this)`。伤害归入实际攻击卡牌，宠物归属仍由现有规则回溯到 Osty 的主人。
4. 能力间接伤害只在能力能够稳定确定唯一来源卡牌时写入 `PowerOriginCardTypes`。本次补充 `HauntPower`、`NecroMasteryPower`、`SleightOfFleshPower` 三条映射。
5. `Soul` 是独立 Token，自身不产生伤害；它触发的能力伤害归入能力映射后的来源卡牌。`SweepingGaze` 是由 `SentryModePower` 生成的独立攻击 Token，伤害归入 `SweepingGaze` 自身，不回溯给 `SentryMode`。
6. 自动打出、生成、克隆得到的卡牌，按实际被打出的卡牌稳定 ID 统计；`Undeath` 克隆牌不单独建立来源。
7. Doom 的指定击杀走 `CreatureCmd.Kill`，不会产生标准 `DamageResult`，因此当前不计入 DPS。这是有意设计，不是漏记伤害事件。
8. 当前 88 张卡牌没有发现玩家生命自损；`BoneShards`、`Sacrifice` 对 Osty 的击杀属于宠物死亡，不计入玩家自损。

## 代码覆盖结果

### 直接伤害

游戏程序集中共有 36 张亡魂契约师卡牌包含伤害指令，其中：

- 24 张从卡牌直接造成伤害：`BansheesCry`、`BlightStrike`、`Bury`、`CaptureSpirit`、`DeathMarch`、`Debilitate`、`Defile`、`DrainPower`、`Eradicate`、`Fear`、`Graveblast`、`Hang`、`Misery`、`PullFromBelow`、`Reap`、`Reave`、`SculptingStrike`、`Severance`、`SoulStorm`、`Sow`、`StrikeNecrobinder`、`TheScythe`、`TimesUp`、`Veilpiercer`。
- 12 张通过 Osty 攻击造成伤害：`BoneShards`、`Fetch`、`Flatten`、`HighFive`、`Poke`、`Protector`、`Rattle`、`RightHandHand`、`SicEm`、`Snap`、`Squeeze`、`Unleash`。

这些路径由 `DamageCmd` / `CreatureCmd.Damage` 携带卡牌上下文，不需要在 `DpsAttribution` 中逐张硬编码；卡牌名、升级版本和同名合并由统计层处理。

### 能力间接伤害

| 卡牌 | 能力 | 触发方式 | 当前归因 | 状态 |
| --- | --- | --- | --- | --- |
| `Haunt` | `HauntPower` | 自己打出 `Soul` | 来源为 `HauntPower`；卡牌明细映射到 `Haunt` | 已覆盖，待运行验证 |
| `NecroMastery` | `NecroMasteryPower` | Osty 失去生命 | 来源为 `NecroMasteryPower`；卡牌明细映射到 `NecroMastery` | 已覆盖，待运行验证 |
| `SleightOfFlesh` | `SleightOfFleshPower` | 对敌人施加非临时减益 | 来源为 `SleightOfFleshPower`；卡牌明细映射到 `SleightOfFlesh` | 已覆盖，待运行验证 |

本次新增的唯一来源映射位于 `DpsAttribution.PowerOriginCardTypes`。`HauntPower` 的伤害调用中 dealer 和 cardSource 均为 `null`，因此需要依赖该映射和模型上下文；`NecroMasteryPower` 使用 `ThrowingPlayerChoiceContext`，也必须在游戏内确认上下文链。

### Osty、Soul 与派生 Token

| 对象 | 伤害路径 | 当前统计落点 |
| --- | --- | --- |
| `SweepingGaze` | 由 `SentryModePower` 每回合生成；`FromOsty(...).TargetingRandomOpponents(...)` 攻击 | `SweepingGaze` |
| `Soul` | 自身只抽牌，无伤害；可触发 `HauntPower`、`DevourLifePower` | 不产生伤害事件；触发伤害按能力映射统计 |
| `Undeath` 克隆牌 | 克隆手牌，后续按实际打出的卡牌上下文结算 | 实际卡牌 ID |
| `Afterlife`、`Bodyguard`、`Cleanse`、`Dirge`、`LegionOfBone`、`PullAggro`、`Reanimate`、`Spur` | 召唤、治疗或管理 Osty | 不产生伤害事件 |
| `BoneShards`、`Sacrifice` 的 Osty 击杀 | `CreatureCmd.Kill(base.Owner.Osty)` | 宠物死亡；不计玩家自损 |

### Doom

`DoomPower.DoomKill` 和 `EndOfDays` 的指定击杀使用 `CreatureCmd.Kill`，不会形成标准伤害结果，因此当前 DPS 统计不记录该次击杀。涉及 Doom 的卡牌包括 `BlightStrike`、`Countdown`、`Deathbringer`、`DeathsDoor`、`EndOfDays`、`NegativePulse`、`Neurosurge`、`NoEscape`、`Oblivion`、`ReaperForm`、`Scourge`、`Shroud`、`TimesUp`。其中 `BlightStrike` 和 `TimesUp` 的直接伤害仍按卡牌正常统计。

### 自损

当前 88 张卡牌的反编译代码没有发现由卡牌直接触发的玩家生命自损。`Haunt` 的 `HpLossVar` 用于配置 `HauntPower` 对敌伤害，不是玩家自损。

- 24 张直接伤害卡和 12 张 Osty 攻击卡是否全部落到自身稳定卡牌 ID。
- Osty 攻击的 dealer 为宠物时，卡牌来源和玩家归属是否保持稳定。
- `HauntPower`、`NecroMasteryPower`、`SleightOfFleshPower` 的唯一来源映射是否覆盖对应运行时上下文。

- `Soul` 触发 `HauntPower` / `DevourLifePower` 时，是否只记录实际伤害并把触发牌作为二级信息。
- `Undeath` 克隆牌和自动生成牌是否按实际卡牌 ID 统计。
- `BoneShards`、`Sacrifice` 的 Osty 死亡是否未被计入玩家自损。
- Doom 击杀是否明确不出现在造成伤害明细中，且不污染其他来源的命中次数。

## 当前限制

- 本文结论来自 `0.107.1` 程序集静态审计，尚未完成游戏内运行态验证。
- 多人游戏中的玩家归属、敌方施加 Doom、敌方能力和遗物/药水产生的能力伤害不在本次单人卡牌范围。
- Doom 击杀不计入 DPS 是当前口径；如果后续需求改为按致命伤害结算，需要单独设计事件和归属规则。
